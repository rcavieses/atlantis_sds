GLOSSA - Global Ocean Species Spatio-temporal Analysis

GLOSSA (Global Ocean Species Spatio-temporal Analysis) is an open-source, user-friendly R Shiny application designed for modeling marine species distribution. Written in R, GLOSSA uses the Shiny and bs4Dash libraries to provide an intuitive interface for fitting species distribution models using presence/absence or presence-only (pseudo-absences will be generated) data. The app uses flexible machine learning techniques like Bayesian Additive Regression Trees (BART), enabling users to model species distributions across different temporal and spatial scales and forecast future scenarios based on environmental data. With GLOSSA, users can explore current and future suitable habitats and visualize results with minimal coding expertise.

Getting started

You can install and run GLOSSA using the following R code:

install.packages("glossa")

library(glossa)
run_glossa()

To install the development version of GLOSSA from GitHub, use:

if (!require("devtools")) 
  install.packages("devtools")

devtools::install_github("iMARES-group/glossa")

Command-line usage (no Shiny)

For batch processing or running GLOSSA on a server/HPC without a browser, run_glossa_cli() runs the same analysis pipeline as the app directly from file paths, for one or several species at once:

library(glossa)

results <- run_glossa_cli(
  pa_files = c(sp1 = "occurrences/sp1.tsv", sp2 = "occurrences/sp2.tsv"),
  fit_layers = "env/fit_layers.zip",
  proj_layers = c(ssp126 = "env/proj_ssp126.zip", ssp585 = "env/proj_ssp585.zip"),
  study_area_poly = "area/study_area.gpkg",
  native_range = c("fit_layers", "projections"),
  suitable_habitat = c("fit_layers", "projections"),
  other_analysis = c("variable_importance", "cross_validation"),
  seed = 123,
  export_dir = "glossa_output/"
)

It can also be called straight from a terminal with Rscript, using inst/scripts/run_glossa.R (run with --help for the full list of options):

Rscript run_glossa.R \
  --pa sp1=occurrences/sp1.tsv --pa sp2=occurrences/sp2.tsv \
  --fit_layers env/fit_layers.zip \
  --proj_layers ssp126=env/proj_ssp126.zip --proj_layers ssp585=env/proj_ssp585.zip \
  --study_area area/study_area.gpkg \
  --native_range fit_layers,projections \
  --suitable_habitat fit_layers,projections \
  --other variable_importance,cross_validation \
  --seed 123 \
  --export_dir glossa_output/
